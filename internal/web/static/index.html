Advanced settings
Network
Each candidate IP is TCP-tested on every port. Default: 443.
Address family
Auto scans both families when this machine has a global IPv6 address, and IPv4 only when it doesn't.
An IPv6 block can't be enumerated (a /64 holds 1.8×10¹⁹ hosts), so addresses are drawn at random from it. 0 = 256 per range.
Performance
Hard-caps concurrency (1 xray / 100 TCP) and stops the background rain. Leave the fields blank for auto (CPU-scaled).
Xray procs = simultaneous xray processes; batch = IPs tested per process.
Stage 2 · Xray confirm
Probe timeout blank = auto (2× max latency, min 1.5s). Lower it to skip dead IPs faster.
Sampling
Randomly picks N IPs out of the whole pool. 0 scans everything.
IPv4 only — an IPv6 range uses its own cap above.
